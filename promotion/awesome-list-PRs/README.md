# Awesome-list PR drafts (AdverseMed-500)

Each file in this directory is a **draft PR body** for a curated
"awesome-*" list on GitHub. Dyuthi submits these herself (so authorship
+ maintainer engagement is under her account).

## Suggested submission order

1. `awesome-medical-ml.md` — strong topical fit; benchmarks section.
2. `awesome-medical-nlp.md` — strong topical fit; datasets/benchmarks
   section.
3. `awesome-llm-evaluation.md` — great fit; calibration + safety
   benchmark.
4. `awesome-ml-safety.md` — high-value fit for the "safety
   benchmarks / abstention" subcategory if the list has one.

## Universal flow (per list)

1. Verify the target list still exists and still accepts PRs.
2. Fork the list repo on GitHub (using `calnugget`, not `vallamsetty`).
3. Clone your fork locally.
4. Edit the README (or relevant section file) to add the exact
   markdown line from the draft.
5. **Alphabetize** within the section (or follow the list's own
   ordering rule).
6. Commit with `Add: AdverseMed-500 (hand-verified false-premise medical benchmark)`.
7. Push to your fork.
8. Open the PR using the title + body from the draft file.

## Rules of engagement

- One PR per list; do not batch.
- Follow the list's `CONTRIBUTING.md` (star counts, alphabetization,
  link-checker, etc.).
- If a list has a "please open an issue first" rule, do that instead.
- Never offer stars-for-stars or paid promotion; grounds for ban.

## After merge

- Add a "featured in" line to the main README (optional).
- Log merged PR URLs in `plans/adoption_log.md` (private dyuthi-research
  repo).
